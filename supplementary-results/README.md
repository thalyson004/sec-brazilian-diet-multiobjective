These pages contain 10 tables and 9 figures from the same experiments described in the article. Table and figure labels begin with S. Section numbers without S refer to the article. Additional plots use the same representative-run rule as the main figures; connecting lines and surfaces do not add feasible diets.

The menu examples use the original Ideal rule on the selected NSGA-II reporting fronts. They illustrate individual menus rather than summarize the 20 replications. Reference-constrained choices use full evaluated histories and are published separately.
